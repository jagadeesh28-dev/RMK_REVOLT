## 1. Architectural Invariant

The SECONDShift scientific decision engine operates purely in the domain of probability distributions, risk integrals, and statistical decision analysis. 

**Under NO circumstances does the research engine issue low-level hardware directives, such as:**
- `digitalWrite(RELAY_PIN, HIGH)`
- Direct GPIO pin manipulation
- Raw PWM timer frequency/duty cycle registers
- Direct ADC hardware gain settings

Instead, research outputs (`OPERATE`, `DERATE`, `RETIRE`, `HOLD`, `TEST`) are translated by the **Actuation Policy Layer** into abstract, strongly-typed **CommandFrames** transmitted via newline-delimited JSON over serial or simulated buses.

## 2. Command Structure

```json
{
  "type": "command",
  "command_id": "a1b2c3d4",
  "action": "OPERATE",
  "requested_mode": "ENABLE_LOAD",
  "timestamp": 1727880000.123,
  "reason": "SOH=0.92, R0=2.0mOhm, P(Failure) <= 0.002, LFP Confirmed",
  "interlock_required": true,
  "current_limit_a": 10.0,
  "pulse_duration_s": null,
  "parameters": {}
}
```

### Parameter Definitions
- `type`: Mandatory literal string `"command"`.
- `command_id`: Unique 8-character hex string for tracking and ACK/NACK matching.
- `action`: High-level scientific action intent (`OPERATE`, `DERATE`, `RETIRE`, `HOLD`, `EMERGENCY_ISOLATE`, `REQUEST_MEASUREMENT`).
- `requested_mode`: Abstract actuator directive (`ENABLE_LOAD`, `LIMIT_LOAD`, `ISOLATE`, `KEEP_ISOLATED`, `EXECUTE_PULSE`).
- `timestamp`: Epoch POSIX timestamp (in seconds) of command generation.
- `reason`: Human- and audit-readable justification generated by the decision engine.
- `interlock_required`: Boolean flag enforcing that hardware contactor cannot close unless the analog comparator (LM393) and watchdog (TPS3823) verify healthy status.
- `current_limit_a`: Upper bound on allowable sink current (Amperes).
- `pulse_duration_s`: Applicable only for `EXECUTE_PULSE` commands.

## 4. Hardware Safety Acknowledgment (ACK / NACK)

The embedded controller (ESP32) must respond to every received command with an immediate structured acknowledgment:

```json
{
  "type": "ack",
  "command_id": "a1b2c3d4",
  "status": "ACCEPTED",
  "hardware_trip": false,
  "timestamp_ms": 123456890
}
```

If the hardware interlock chain (LM393 / TPS3823 / KSD9700) is open, or if parameters exceed SELV safety limits, the embedded firmware must reject the command with `NACK`:

```json
{
  "type": "nack",
  "command_id": "a1b2c3d4",
  "status": "REJECTED",
  "error_code": "ERR_INTERLOCK_OPEN",
  "reason": "LM393 analog comparator detects V_cell < 2.00V",
  "hardware_trip": true,
  "timestamp_ms": 123456890
}
```
